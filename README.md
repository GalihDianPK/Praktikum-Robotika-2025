# Modul Praktikum Robotika PTA 2025-2026

Repositori ini berisi dokumentasi dan kode sumber untuk praktikum Robotika di Pusat Studi Multimedia & Robotika (PSMURO) Universitas Gunadarma.

## 📂 Struktur Proyek
- **Bab 1 (IoT):** Konsep dasar, input/output, dan perangkat IoT.
- **Bab 2 (Voice Robot):** Implementasi kontrol robot menggunakan perintah suara via HC-05.
- **Bab 3 (Wall Follower):** Algoritma navigasi robot mengikuti dinding.
- **Bab 4 (Robot Crawler):** Implementasi penggerak robot crawler.
- **Bab 5 (Robot Vision):** Integrasi Machine Learning & Robot Vision.

## 🛠️ Persyaratan
- Arduino IDE
- Library Pendukung (tergantung bab masing-masing)
- Hardware: Arduino Uno, WeMos ESP8266, Motor Driver, dll.

## 📝 Catatan
Proyek ini dikembangkan sebagai bagian dari kurikulum praktikum Universitas Gunadarma.
